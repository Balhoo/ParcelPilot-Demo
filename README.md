# ParcelPilot — demo pública

Laboratorio original de operaciones de paquetería por Alan Berra Garcia.

Demo gratuita: https://balhoo.github.io/ParcelPilot-Demo/

Registra envíos ficticios, asigna repartidores, documenta incidencias, resuelve y entrega. Incluye búsqueda, historial y respaldos JSON. Los datos de esta demo se guardan solamente en el navegador; no hay cuentas, servidor de operaciones ni transportistas conectados.

Este repositorio contiene exclusivamente la compilación estática. El código fuente y la API se conservan en un repositorio privado separado. No introduzcas información personal real. No es un servicio de paquetería real.
